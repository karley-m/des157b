How Many?

This function takes a number and inserts it into a string sentence.

Named Function

            function cats(quantity){
                return 'I have ' + quantity + ' cats.';
            }

            console.log(cats(4));

Function Expression

            const cats = function(quantity){
                return 'I have ' + quantity + ' cats.';
            }

            console.log(cats(6));

Arrow Function

            const cats = (quantity) => 'I have ' + quantity + ' cats.';

            console.log(cats(19));
