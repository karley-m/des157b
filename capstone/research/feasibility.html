Feasibility Report

Features I plan to include:

  • Seven steps that display 3 to 4 options for each category for the user to choose from.
  • Hover states on each option in each category that defines metrics like scores, impacts, and benefits.
  • A drag and drop canvas to assemble the pieces of the kit.
  • A scrollable "neighborhood" displaying a collection of user's designs.

Technologies required to build each:

  • Capturing user's choices throughout the seven steps with DOM capture and storing the choices in Back4App database.
  • Tippy.js library for having text appear on hover states for the choices.
  • Fabric.js library for creating a canvas that allows users to drag, resize, and rotate the images and be able to save the final image to local downloads.
  • Animating text transitions with GSAP.

Assessment of these requirements:

  • I am familiar with Back4App's workflow since I used it with the Library Liberty project. However, since this is for capturing choices instead of strings, I will have to learn new functions within the database.
  • I think working with Tippy.js and Fabric.js will be straightforward.

Identifying difficulties:

  • A difficulty that comes to mind is getting the user's specific options to display on the Fabric.js canvas at the end of the narrative and how to capture the design as a flat image to present in the neighborhood, the very last scene. My best guess at the moment is to capture the choices through Back4App, create a number system that correlates those with images, and furthermore, capture an individual image ID from the canvas to display in the neighborhood.
